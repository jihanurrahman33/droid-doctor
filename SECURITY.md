# Security policy

## Reporting a vulnerability

Please report security problems privately, using
[GitHub's private vulnerability reporting](https://github.com/jihanurrahman33/droid-doctor/security/advisories/new).
Don't open a public issue for them.

droid_doctor reads and, with `fix`, edits files in the project you point it at.
Reports about unsafe edits (for example a path outside the project, or
overwriting files changed after a fix) are in scope, as are problems in the
release binaries, the GitHub Action and the data download (`data update`).

You can expect an acknowledgement within a few days.

## Supported versions

Only the latest release receives fixes.
